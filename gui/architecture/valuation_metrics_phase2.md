# Phase 2 typed valuation inputs

Each new Gemini report retains its raw response and Phase 1 assumption audit. `structure_report_metrics` converts candidate audit rows into `FinancialMetric` records with controlled assumption, production-stage, share-basis and unit types. It preserves raw values and units alongside deterministic normalized values and a conversion label. Null means the evidence did not establish the field. Invalid stage/unit claims remain in the raw response and surface as `INVALID_METRIC` warnings instead of becoming typed facts.

`financial_metrics` is an additive, append-only PostgreSQL table keyed by `metric_id` and linked to `deepresearch_versions.report_id`. Records are inserted in the same transaction as the version and current-report pointer. The version archive's `result.json` also contains `structured_metrics` and `metric_warnings`. The existing target price and DCF/SOTP text are still generated by Gemini; no Python valuation model is called.

Validation is advisory: comparable newer company disclosures trigger `STALE_INPUT`; unknown production stages, share bases and commodity-price units, missing production/cost periods, ROM or contained metal used as direct saleable revenue, capacity used as production, management targets used as guidance, and weighted-average historical shares used for a forward target produce warnings. Future deterministic valuation code can call the strict compatibility helpers before calculating revenue or a target.

Legacy reports have no structured Gemini fields, exact original prompt, or verified report-source linkage unless Phase 1 archived them at generation. The Jubilee inspection in `tmp/jubilee_phase2_audit.json` converts the surviving report's audit conservatively: 12,000 tonnes has no verified stage/source, the report's $5,950/t AISC has no demonstrated period/source, 3,146,295,996 shares have no verified basis in the report, and ZAR1.70 is a previous-report carry-forward. Its separate comparison metrics are a regression fixture from identifiable disclosures; they are not retroactively asserted as inputs to that generation. The official H1 FY2025 report records $5,948/t for July?December 2024; the company H1 FY2026 announcement records $8,062/t for July?December 2025. Neither establishes that the legacy report's rounded $5,950 was sourced from that older report, nor that the disclosed cost was AISC.

For Phase 3, connect source-specific extraction to archived source IDs and exact evidence quotes, separate reported cost definitions and production recovery/payability bridges, then make a deterministic DCF/SOTP model consume only validated typed inputs. Version and compare any calculated target separately from Gemini narrative before making it authoritative.
